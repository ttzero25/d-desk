# D-Desk

시험 기간을 위한 개인용 학습 대시보드. 주차별 학습 계획, 캘린더, 시험 D-day, 그리고 옵시디언 스타일 메모를 한 곳에서 관리합니다.

**웹:** https://ttzero25.github.io/d-desk/

## 탭 구성

### Home
- **다음 시험 D-day** 카드
- **선택한 날** — 캘린더에서 고른 날짜의 시험 공부 계획·시험·과제를 표시
- **캘린더** — 시험(테두리)·과제 마감을 월간으로, 공휴일 표기. 날짜를 누르면 그 날 상세/일정 추가
- **가장 급한 일정** — D-day 순 정렬

### School
- **요약 타일** — 다음 시험/남은 시험(실제 시험일 기준), 오늘 학습량, 남은 할 일 (주차별 계획 진행 기준)
- **캘린더** — 시험/고사는 **빨간 테두리**, 과제/발표는 **주황 테두리**, 주차별 계획일은 accent 점으로 표시
- **주차별 계획표** — 날짜별 목표량을 담은 고정 계획표
  - 날짜별 **완료 체크박스**(자동 저장) · **완료율 진행 바** · **오늘 날짜 강조**
  - **공휴일은 빨간색**으로 표기, 접기/펼치기 지원
- **학교 할 일** — 시험·과제 목록, 완료 체크

### CommSec · ASC · etc
- 카테고리별 캘린더와 할 일(연구실/동아리/기타) 관리

### Memo (옵시디언 스타일)
- **그래프 화면** — 노트가 점(dot)으로 떠 있고, **내용이 비슷한 노트끼리 자동으로 선 연결**(코사인 유사도)
- 왼쪽 **노트 목록**, 오른쪽 **그래프**. 노트를 누르면 편집, 같은 노트를 다시 누르면 그래프로 복귀
- **마크다운 편집 + 실시간 미리보기**(나란히/편집), 입력 즉시 자동 저장
- **발행** — 깔끔한 리딩 뷰로 렌더링
- 여러 노트 생성/삭제 지원

## 일정 추가
- 상단 **일정** 버튼 또는 캘린더 날짜 클릭으로 추가
- 내용·분류·시작/종료일·시간·**반복**(매일/매주/격주/매월)·연결 과목·메모 지정
- **시험/고사로 표시**(빨강) 또는 **과제/발표로 표시**(주황) 선택

## 기타 기능
- **뽀모도로 타이머** (25/5 등, 과목 선택)
- **데이터 백업/복원** — 모든 데이터를 JSON 파일로 내보내기/가져오기 (헤더 버튼)
- **설정** — 요일별 시간표(공강 반영)·학습 시작일
- **학습 알림**(브라우저 알림)
- 라이트/다크 테마 전환

## 저장 방식
- 기본적으로 브라우저 `localStorage`에 저장되어 단독 동작합니다.
- claude.ai Artifact로 게시하면 `db` 런타임으로 여러 기기에서 동기화됩니다(같은 계정, 비공개).
- 브라우저별로 저장되므로 캐시 삭제·기기 이동 전에는 **백업 기능**으로 내보내 두세요.

## 실행
정적 HTML 한 파일입니다.
- 브라우저에서 `index.html`을 바로 열면 동작합니다(localStorage 저장).
- 배포는 GitHub Pages 등 정적 호스팅에 파일을 올리기만 하면 됩니다.

## 스택
- 순수 HTML/CSS/JS (프레임워크·외부 런타임 의존성 없음, 마크다운 렌더러도 자체 구현)
- 폰트: IBM Plex Sans KR / IBM Plex Mono (Google Fonts)
