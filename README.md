# D-Desk

시험 기간을 위한 개인용 학습 대시보드. 주차별 학습 계획, 캘린더, 시험 D-day, 그리고 옵시디언 스타일 메모를 한 곳에서 관리합니다.

**웹:** https://ttzero25.github.io/d-desk/

## 탭 구성
- **Home** — 다음 시험 D-day, 선택한 날 상세, 월간 캘린더, 급한 일정
- **School** — 요약 타일, 시험/과제 캘린더, 주차별 계획표(체크·진행률), 학교 할 일
- **CommSec · ASC · etc** — 연구실/동아리/기타 카테고리별 일정
- **Memo** — 옵시디언 스타일 마크다운 노트(그래프·자동 연결·발행)

## 기능
- **일정 추가** — 반복·시간·연결 과목 지정, 시험/고사(빨강)·과제/발표(주황) 표시
- **뽀모도로 타이머** (25/5 등, 과목 선택)
- **데이터 백업/복원** — 모든 데이터를 JSON 파일로 내보내기/가져오기 (헤더 버튼)
- **설정** — 요일별 시간표(공강 반영)·학습 시작일
- **학습 알림**(브라우저 알림)
- 라이트/다크 테마 전환

## 저장 방식
- 기본적으로 브라우저 `localStorage`에 저장되어 단독 동작합니다.
- claude.ai Artifact로 게시하면 `db` 런타임으로 여러 기기에서 동기화됩니다(같은 계정, 비공개).
- 브라우저별로 저장되므로 캐시 삭제·기기 이동 전에는 **백업 기능**으로 내보내 두세요.

## 실행
정적 HTML 한 파일입니다.
- 브라우저에서 `index.html`을 바로 열면 동작합니다(localStorage 저장).
- 배포는 GitHub Pages 등 정적 호스팅에 파일을 올리기만 하면 됩니다.

## 스택
- 순수 HTML/CSS/JS (프레임워크·외부 런타임 의존성 없음, 마크다운 렌더러도 자체 구현)
- 폰트: IBM Plex Sans KR / IBM Plex Mono (Google Fonts)
