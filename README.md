# D-Desk

시험 과목·시험일·과제를 넣으면 **시험일 역산 분산 학습 일정**과 과목별 자료를 한 화면에서 보여주는 개인용 시험기간 대시보드. 시험 D-day를 한눈에.

**웹:** https://ttzero25.github.io/d-desk/

## 기능

- **요약 타일** — 다음 시험 D-day, 남은 시험 수, 오늘 공부할 과목 수, 남은 과제 수
- **오늘 할 일** — 오늘 공부할 과목(완료 체크)과 마감 임박 과제
- **학습 일정** — 시험일에서 역산해 과목별 공부 세션을 남은 날짜에 고르게 분산
  (시험이 가까울수록·공부 강도가 높을수록 세션을 더 많이, 마지막 세션은 시험 전날 최종복습)
  공휴일·바쁜 날은 자동으로 피해서 배치
- **캘린더** — 월간 화면에서 시험·과제·공부 세션을 카테고리 색상 범위 바로 표시, 공휴일 표기.
  날짜를 클릭하면 그 날을 시작일로 새 항목 추가
- **반복 일정** — 매일/매주 등 반복 항목과 시간대(오전/오후/저녁) 지정
- **과목 카드** — D-day 색상(임박/곧/여유), 학습 진도 바, 자료 링크, 메모
- **과제 목록** — 완료 체크, 마감 지남/임박 강조
- 라이트/다크 테마 전환

## 저장 방식

- claude.ai Artifact로 게시하면 `db` 런타임 기능으로 **여러 기기에서 동기화**됩니다(같은 계정 로그인 기준, 비공개).
- 그 밖의 환경에서는 자동으로 브라우저 `localStorage`로 폴백해 단독 동작합니다.

## 실행

정적 HTML 한 파일입니다.

- 브라우저에서 `index.html`을 바로 열어도 동작합니다(이 경우 localStorage에 저장).
- 기기 간 동기화가 필요하면 claude.ai의 Artifact로 게시해 사용하세요.

## 스택

- 순수 HTML/CSS/JS (프레임워크 없음)
- 폰트: IBM Plex Sans KR / IBM Plex Mono (Google Fonts)
